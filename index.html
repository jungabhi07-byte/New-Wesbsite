Ch 1 Introduction to Machine Learning

4 hours

1.1 What is Machine Learning?

Machine Learning (ML) is a subset of Artificial Intelligence (AI) that enables systems to learn and improve from experience without being explicitly programmed. ML algorithms build mathematical models based on training data to make predictions or decisions.

1.2 Difference: AI, ML, DL

AI Broadest field — machines mimicking human intelligence.
ML Subset of AI — systems that learn from data.
DL Subset of ML — uses neural networks with many layers.

Hierarchy: DL ⊂ ML ⊂ AI

1.3 ML System & Components

  • Data: Raw input (features & labels).
  • Feature Engineering: Transforming raw data into meaningful features.
  • Model: The algorithm (e.g., Neural Network, SVM).
  • Loss Function: Measures prediction error (e.g., MSE, Cross-Entropy).
  • Optimizer: Adjusts weights to minimize loss (e.g., SGD, Adam).
  • Evaluation: Metrics like accuracy, precision, recall.

1.4 ML Ecosystem & Data Concerns

  • Ecosystem: Data storage, compute (GPUs/TPUs), feature stores, model serving, monitoring.
  • Data Concerns:
    • Quality: Missing values, noise, outliers.
    • Bias: Sampling bias, label bias.
    • Drift: Data drift (input changes) and concept drift (target changes).
    • Privacy: GDPR, anonymization.

1.5 Overfitting & Underfitting

Overfitting

  • Model learns training data too well, including noise.
  • High Variance
  • Poor generalization to test data.
  • Fixes: More data, regularization, dropout, simpler model.

Underfitting

  • Model is too simple to capture patterns.
  • High Bias
  • Poor performance on both train and test.
  • Fixes: More complex model, better features, longer training.

1.6 The Bias-Variance Trade-Off

As model complexity increases:

  • Bias decreases (model becomes more flexible).
  • Variance increases (model becomes sensitive to training data).

The goal is to find the sweet spot that minimizes total error.

Total Error = Bias² + Variance + Irreducible Error

Ch 6 Convolutional Neural Networks (CNNs)

8 hours

6.1 Introduction, Properties, Need, CNN vs MLP

CNN: A specialized neural network for processing grid-like data (images, videos).

Properties of CNN

  • Local Connectivity: Neurons connect to local regions.
  • Weight Sharing: Same filter weights across the image.
  • Translation Invariance: Detects features regardless of position.

CNN vs MLP

  • MLP: Fully connected, huge parameters for images.
  • CNN: Fewer parameters, exploits spatial structure.
  • CNN is more efficient and more accurate for vision tasks.

6.2 Convolution, Pooling, Padding, Flattening, FC Layer

  • Convolution: Sliding a filter (kernel) over input to produce feature maps.
  • Pooling: Downsampling to reduce dimensions.
    • Max Pooling: Takes maximum value in each region.
    • Average Pooling: Takes average value.
    • Global Pooling: Reduces each feature map to a single value.
  • Padding: Adding zeros around input. Same padding preserves dimensions.
  • Stride: Steps the filter moves.
  • Flattening: Converts 2D feature maps to 1D vector.
  • Fully Connected (FC) Layer: Dense layer for final classification.
Output Size = ((Input - Filter + 2*Padding) / Stride) + 1

6.3 Training a Network, Training Cycle, One-Hot Encoding

  • Training Cycle:
    1. Forward pass → compute loss.
    2. Backward pass → compute gradients.
    3. Update weights (optimizer).
  • One-Hot Encoding: Converts class labels into binary vectors (e.g., class 3 of 5 → [0,0,1,0,0]). Used with cross-entropy loss.
  • Batch Size: Number of samples per update. Epoch: One full pass through the dataset.

6.4 CNN Forward & Backward Propagation

  • Forward: Input → Convolution → Activation (ReLU) → Pooling → ... → FC → Softmax → Output.
  • Backward: Gradients flow backward through FC, pooling, and convolution layers using the chain rule.
  • Convolution backprop involves flipping the kernel (transposed convolution).

6.5 CNN Architectures

AlexNet (2012) — Pioneered deep CNNs; used ReLU, dropout.
VGG (2014) — Simple, uniform 3x3 convolutions, very deep (16-19 layers).
GoogLeNet (2014) — Inception modules with parallel filters; efficient.
ResNet (2015) — Skip connections (residual blocks) enable 100+ layers.
DenseNet (2016) — Each layer connects to all previous layers; encourages feature reuse.

Ch 7 Recurrent Neural Networks (RNNs)

6 hours

7.1 Introduction to RNNs

RNN: Neural networks designed for sequential data where order matters. They have a hidden state that acts as a memory of past inputs.

Unlike feedforward networks, RNNs share weights across time steps, making them parameter-efficient for sequences.

7.2 Sequence Modeling

Sequence modeling involves predicting the next element(s) in a sequence.

Architecture Types

  • Many-to-One: Sequence → single output (e.g., sentiment analysis).
  • One-to-Many: Single input → sequence (e.g., image captioning).
  • Many-to-Many: Sequence → sequence (e.g., language translation).

Key Concepts

  • Hidden State (hₜ): Summary of sequence up to time t.
  • hₜ = f(Wₓₕ·xₜ + Wₕₕ·hₜ₋₁ + b)
  • Training uses Backpropagation Through Time (BPTT).

7.3 Vanilla RNN, LSTM, GRU

Vanilla RNN

  • Simple recurrent connection.
  • Problem: Vanishing / exploding gradients.
  • Cannot capture long-range dependencies.

LSTM

  • 3 gates: Forget, Input, Output.
  • Has cell state (cₜ) and hidden state (hₜ).
  • Can remember information for long periods.

GRU

  • 2 gates: Update, Reset.
  • Simpler than LSTM (no separate cell state).
  • Performs similarly to LSTM with fewer parameters.

7.4 Bi-directional RNNs

Bi-directional RNNs process sequences in both forward and backward directions using two hidden states that are concatenated.

  • Use Case: Tasks where both past and future context are needed (e.g., NER, speech recognition).
  • Not suitable for real-time streaming where future is unknown.

7.5 Applications: Language Translation & Captioning

Language Translation

  • Sequence-to-Sequence (Seq2Seq) architecture.
  • Encoder RNN → context vector → Decoder RNN.
  • Often uses Attention to improve performance.

Image Captioning

  • CNN extracts image features (encoder).
  • RNN/LSTM generates caption (decoder).
  • One-to-Many architecture: image → sequence of words.

Summary

CNNs excel at spatial data (images) with weight sharing and local connectivity.

RNNs excel at sequential data (text, time series) with hidden state memory.

LSTMs & GRUs solve the vanishing gradient problem of vanilla RNNs.
