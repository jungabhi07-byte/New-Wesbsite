Chapter 2: Supervised Learning

2.1 Parametric vs. Nonparametric

  • Parametric: Assumes a fixed form for the model (e.g., Linear Regression). Fast but rigid.
  • Nonparametric: Flexible; the number of parameters grows with data (e.g., KNN, Decision Trees).

2.2 Regression

Predicts continuous values. Uses loss functions like Mean Squared Error (MSE) to optimize parameter estimation.

2.3 Classification Algorithms

Logistic Regression: Binary output probability.
Naïve Bayes: Probabilistic classification using Bayes' Theorem.
K-Nearest Neighbors: Instance-based voting system.
Random Forest: Bootstrap aggregation (bagging) of trees.

Chapter 6: Convolutional Neural Networks (CNNs)

6.1 & 6.2 Core Components

CNNs utilize spatial structure, making them superior to standard MLPs for vision tasks.

  • Convolution: Feature extraction using filters.
  • Pooling: Reduces spatial dimensions (Max, Average).
  • Padding: Keeps spatial sizing intact at borders.
